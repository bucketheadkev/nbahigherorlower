# Design tooling (local)

## figma-mcp-bridge-plugin/

Prebuilt **Figma MCP Bridge** plugin (v0.0.29) from [gethopp/figma-mcp-bridge](https://github.com/gethopp/figma-mcp-bridge).

Import in Figma Desktop: **Plugins → Development → Import plugin from manifest…** → `figma-mcp-bridge-plugin/manifest.json`.

Pairs with Cursor MCP server `figma-bridge` (`npx -y @gethopp/figma-mcp-bridge`).
